- O vídeo fornecido é “New Open-Source AI Animation is Here!” (PixelArtistry, 04/10/2026); o fluxo principal apresentado é UniMate, texto→movimento para esqueletos rigados. - O repo assume Python 3.10 e `torch==2.5.1+cu124`. No host, só testamos Python 3.14/3.11 e Blender 5.2.2; o `torch` instalado falha ao importar por falta de runtime CUDA, sem `nvidia-smi`/`rocminfo`.
